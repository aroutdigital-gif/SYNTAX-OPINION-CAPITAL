# Syntax Opinion Capital

Vercel-ready Next.js landing page for Syntax Opinion Capital.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Upload this project to GitHub.
2. Import the repository in Vercel.
3. Framework preset: Next.js.
4. Build command: `next build`.
5. Deploy.

## Replace before launch
- WhatsApp number in `app/page.tsx` (`https://wa.me/6280000000000`)
- Telegram URL
- Instagram URL
- Testimonials/images if desired
- Any broker/FTM links
